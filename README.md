

### Sobre mim
Sou estudante de Desenvolvimento de Sistemas, com interesse em Desenvolvimento Backend, Engenharia de Software, Arquitetura de Software, Inteligência Artificial e Automação de Sistemas. Tenho experiência no desenvolvimento de aplicações utilizando Node.js, FastAPI e React Native, atuando na criação de APIs, integrações entre serviços e aplicações escaláveis. Gosto de trabalhar com APIs REST e integrações utilizando serviços públicos e de terceiros, além de automatizar processos com ferramentas como n8n. Atualmente venho aprofundando meus conhecimentos em análise de dados com Supabase, modelagem e implementação de bancos de dados utilizando MySQL e Firebase, bem como realizando o deploy de aplicações através de plataformas como Vercel e Netlify. Também venho estudando e praticando o desenvolvimento de aplicações baseadas em Inteligência Artificial, incluindo a criação e integração de LLMs, agentes de IA e fluxos inteligentes para automação e processamentousando N8N. Além disso, possuo experiência com desenvolvimento de jogos em Luau (Roblox Studio), onde desenvolvi sistemas e mecânicas voltadas para multiplayer.
